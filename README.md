# Практическая работа: инструкция по запуску

**Группа 126 · Студент № 9**

## Подготовка

Понадобятся Java 8 или новее и [RARS 1.6](https://github.com/TheThirdOne/rars/releases/tag/v1.6). Скачайте `rars1_6.jar` из раздела Assets. В терминале, открытом в папке с этим файлом, выполните:

```text
java -jar rars1_6.jar
```

В **Settings** выберите режим **RV32**, разрешите `Permit extended (pseudo) instructions and formats`. Снимите флажки `Assemble all files in directory` и `Assemble all files currently open` — программы выполняются отдельно.

## Выполнение

1. Откройте нужный файл через **File → Open**.
2. Соберите программу: **Run → Assemble**.
3. Начните выполнение: **Run → Go**.
4. Введите данные в **Run I/O**, нажимая **Enter** после каждого числа. Приглашение к вводу не выводится.

| Файл | Пример ввода | Результат |
|---|---|---|
| `task_a.asm` | `9` | `1` |
| `task_b.asm` | `108` | `108 117 126` |
| `task_c.asm` | `5`, `-8`, `0` — каждое с новой строки | `Count: 2`, `Array: 5 -8` |

Для третьей программы ввод заканчивается по нулю либо после 25 сохранённых чисел. Ноль в массив не включается. Шаг во второй программе равен 9; значения варианта уже заданы в коде.

Повторный запуск: **Run → Reset → Run → Go**. Если код был изменён, сохраните файл и повторите **Assemble** перед запуском.
